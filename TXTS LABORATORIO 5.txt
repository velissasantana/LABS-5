

PRACTICA 2 - CLUSTER DE ALTA DISPONIBILIDAD (CENTOS / PACEMAKER)

RED BRIDGED (ens37):
Servidor 1: 10.0.0.201/24
Servidor 2: 10.0.0.202/24
IP flotante propuesta: 10.0.0.203/24

IMPORTANTE:
- Las dos máquinas deben comunicarse por ens37 antes de continuar.
- Verifica que 10.0.0.203 esté libre y fuera del rango DHCP antes de asignarla.
- No modificar las interfaces NAT ni Host-only.
- La desactivación de STONITH se usa SOLO para esta práctica de laboratorio; no para producción.

1. EN AMBOS SERVIDORES

sudo dnf install -y pcs pacemaker corosync resource-agents fence-agents-all
sudo systemctl enable --now pcsd
sudo passwd hacluster

(Establecer la MISMA contraseña de hacluster en ambos servidores.)

2. NOMBRES DE EQUIPO

SOLO SERVIDOR 1:
sudo hostnamectl set-hostname servidor1

SOLO SERVIDOR 2:
sudo hostnamectl set-hostname servidor2

EN AMBOS SERVIDORES:
echo '10.0.0.201 servidor1' | sudo tee -a /etc/hosts
echo '10.0.0.202 servidor2' | sudo tee -a /etc/hosts
sudo firewall-cmd --permanent --add-service=high-availability
sudo firewall-cmd --reload

3. SOLO EN SERVIDOR 1 - CREAR CLUSTER

sudo pcs host auth servidor1 servidor2 -u hacluster
sudo pcs cluster setup HA01 servidor1 servidor2
sudo pcs cluster start --all
sudo pcs cluster enable --all
sudo pcs status

(Detenerse si la autenticación o creación del clúster muestra errores.)

4. SOLO EN SERVIDOR 1 - CONFIGURAR IP FLOTANTE

sudo pcs property set stonith-enabled=false
sudo pcs resource create IP_FLOTANTE ocf:heartbeat:IPaddr2 ip=10.0.0.203 cidr_netmask=24 nic=ens37 op monitor interval=10s
sudo pcs status

5. PRUEBAS

1. INICIAR LA GRABACION - SERVIDOR 1
sudo pcs status

Verificar que ambos nodos esten Online y que IP_FLOTANTE este Started en servidor1. Si esta en servidor2, intercambiar los roles de los servidores en los pasos siguientes.

2. SERVIDOR 2 - TERMINAL 1
ping 10.0.0.203

Dejar el ping ejecutandose y grabar que responde.

3. SERVIDOR 1 - REINICIAR EL NODO QUE TIENE LA IP FLOTANTE
sudo reboot

4. SERVIDOR 2 - TERMINAL 2 (SIN DETENER EL PING)
sudo pcs status
ip -4 addr show ens37

Comprobar que IP_FLOTANTE paso a servidor2 y que aparece 10.0.0.203 en ens37. Mostrar la recuperacion del ping. Si no se recupera, detener la prueba y revisar el estado; no reiniciar el segundo nodo.

5. ESPERAR QUE SERVIDOR 1 VUELVA A ENCENDER
sudo pcs status

Confirmar que ambos nodos estan Online antes de continuar.

6. SERVIDOR 1 - TERMINAL 1
ping 10.0.0.203

Dejar el ping ejecutandose.

7. SERVIDOR 2 - REINICIAR
sudo reboot

8. SERVIDOR 1 - OTRA TERMINAL
sudo pcs status
ip -4 addr show ens37

Comprobar que IP_FLOTANTE paso a servidor1 y que el ping se recupera.

9. FINAL DEL VIDEO
Esperar que ambos servidores esten encendidos.
sudo pcs status

PRACTCA 3
SERVIDOR 1 — 10.0.0.201

sudo dnf install -y httpd keepalived
sudo systemctl enable --now httpd
echo "<h1>Bienvenido a SERVER 1 - servidor1</h1>" | sudo tee /var/www/html/index.html

sudo tee /etc/keepalived/keepalived.conf > /dev/null <<'EOF'
vrrp_instance VI_1 {
    state MASTER
    interface ens37
    virtual_router_id 54
    priority 100
    advert_int 1
    unicast_src_ip 10.0.0.201
    unicast_peer {
        10.0.0.202
    }
    authentication {
        auth_type PASS
        auth_pass hahttp54
    }
    virtual_ipaddress {
        10.0.0.204/24
    }
}
EOF

if systemctl is-active --quiet firewalld; then
    sudo firewall-cmd --permanent --add-service=http
    sudo firewall-cmd --permanent --add-rich-rule='rule protocol value="vrrp" accept'
    sudo firewall-cmd --reload
fi

sudo systemctl enable --now keepalived
sudo systemctl restart keepalived
sudo systemctl status keepalived --no-pager
ip addr show ens37
curl http://localhost
sudo dnf install -y httpd keepalived curl
sudo systemctl enable --now httpd

echo '<h1>SERVER2 - Servidor 2</h1>' | sudo tee /var/www/html/index.html

curl http://localhost

sudo tee /usr/local/sbin/check_httpd.sh >/dev/null <<'EOF'
#!/bin/bash
/usr/bin/curl -fsS --max-time 2 http://127.0.0.1/ >/dev/null
EOF

sudo chmod 755 /usr/local/sbin/check_httpd.sh

sudo tee /etc/keepalived/keepalived.conf >/dev/null <<'EOF'
global_defs {
    router_id SERVER2
    enable_script_security
    script_user root
}

vrrp_script chk_httpd {
    script "/usr/local/sbin/check_httpd.sh"
    interval 2
    fall 2
    rise 2
}

vrrp_instance VI_HTTP {
    state BACKUP
    interface ens37
    virtual_router_id 54
    priority 100
    advert_int 1
    unicast_src_ip 10.0.0.202
    unicast_peer {
        10.0.0.201
    }
    authentication {
        auth_type PASS
        auth_pass hahttp54
    }
    virtual_ipaddress {
        10.0.0.204/24 dev ens37
    }
    track_script {
        chk_httpd
    }
}
EOF

if systemctl is-active --quiet firewalld; then
    sudo firewall-cmd --permanent --add-service=http
    sudo firewall-cmd --permanent --add-rich-rule='rule protocol value="vrrp" accept'
    sudo firewall-cmd --reload
fi

sudo systemctl enable --now keepalived
sudo systemctl is-active keepalived
ip -4 addr show ens37
